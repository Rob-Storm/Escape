# Overview

This game + engine was inspired by a Ludum Dare stream by Notch where he made Prelude of the Chambered.

It uses Raylib_cs for all of the graphical boilerplate and ImGui (RLImGui for Raylib_cs compatibility) for the level editor.

Most of the development time was spent on the level editor, learning the ins and outs of ImGui. I'm used to WPF and retained-mode GUIs for desktop applications so this was a new experience for me
